## Project Overview

A Hexo 7.3.0 blog (huanyp.cn) using the NexT theme (git submodule). Content is in Chinese. Deployed to GitHub Pages via CI on push to `main`.

## Commands

```bash
npm run new        # Interactive CLI to create a new post (prompts for title, category, tags)
npm run build      # hexo generate — build static site
npm run clean      # hexo clean — clear cache and public/
npm run server     # hexo server — local dev server (localhost:4000)
npm run deploy     # hexo deploy — git push to GitHub Pages
```

Build requires Pandoc installed (used by hexo-renderer-pandoc).

## Architecture

### Content Structure

Posts live in `source/_posts/` organized by category directories:

| Category | Directory | Subcategories |
|----------|-----------|---------------|
| 技术 | `技术/` | 基础知识, 软件设计, AI 工具, 生产工具, 开源项目, 日志 |
| 生活 | `生活/` | (none) |
| 算法竞赛 | `算法竞赛/` | 算法, 题解, 比赛, 代码技巧, 考试总结 |
| 学习 | `学习/` | 笔记, 资料, 工具 |

### Post Frontmatter

```yaml
---
title: Post Title
categories:
  - 技术
tags:
  - tag1
abbrlink: hex_crc32   # auto-generated by hexo-abbrlink on build
date: 2025-04-10 16:33:05
---
```

- `abbrlink` is auto-generated (CRC32 hex) — never set manually
- Permalink format: `posts/:abbrlink.html` — stable across renames/moves

### Key Configuration

- `_config.yml` — Hexo site config (permalink, plugins, deploy target)
- `_config.next.yml` — NexT theme overrides (scheme: Gemini, dark mode, MathJax)
- `themes/next/` — theme as git submodule, do not edit directly
- `source/_data/styles.styl` — custom CSS overrides
- `source/_data/body-end.njk` — injected scripts

### Plugins & Tools

- `hexo-abbrlink` — stable permalink generation
- `hexo-renderer-pandoc` — Pandoc-based markdown (supports more syntax than marked)
- `hexo-generator-index-pin-top` — pin posts with `top: true` in frontmatter
- `plugins/blog-writer/` — Python CLI tool for AI-assisted content generation

### CI/CD

GitHub Actions (`.github/workflows/deploy.yml`): on push to `main`, builds with Node 20 + Pandoc, deploys to GitHub Pages.
